## I — 方法论骨架

这是全书分析工序的"总装台"：把前面各章分散的指标收口成一张买入前核查表，每只股票最多花一两个小时过完。结构分两层——通用层六项，任何股票都要过；专项层六张表，按公司类型只跑对应那张。

为什么要分层：指标有类型适用性。同一份收益记录，周期股的时断时续是常态，稳定增长股的时断时续是警报；同一个低市盈率，在成长股是便宜、在周期顶部恰恰是卖点。用错类型的口径比不查更危险，所以"先归型、再套表"是这张表的第一步，不是可选项。

每类公司的命门不同，专项层就是照命门设计的：缓慢增长型的存在理由是股息，查派息记录与派息缓冲；稳定增长型几乎不会倒闭，关键只剩买入价格；周期型查存货与周期位置，市盈率要反着读；快速增长型查异地复制是否已被证明、增长空间还剩多少；困境反转型先问能否活到好转那天（现金与债务），再问好转的步骤；隐蔽资产型查资产是什么、值多少、谁来兑现。

产出是一张核查表：每项判定"达标／利好／警示／缺口"，数据拿不到就如实标"缺口"，不猜值。清单本身不给买卖结论——估值判定、财务复算、下单前独白是后续工序，本卡负责把缺口和下一步路由说清楚。

## A1 — 应用示例

### 案例1（原书案例，worked_example）：德州仪器——困境反转专项层的"重整步骤"条目（15.1.6，L3310）

输入：1983年10月，德州仪器宣布放弃家用电脑业务（竞争对手如林的热门行业），当年仅该业务就亏损5亿多美元，同步冲销一大笔资产。
执行：按15.1.6专项层逐条——条目④"打算怎样摆脱困境重整旗鼓？剥离赔钱子公司了吗？"：放弃年亏5亿的业务＝真实止血步骤，集中力量经营强项半导体与军用电子设备；条目⑤"业务正在好转吗"：强项业务完整保留；条目⑥"正在削减成本吗"：剥离本身就是最大的成本削减。
输出：宣布放弃家用电脑业务的第二天，股价从每股101美元涨到124美元，4个月后涨到176美元。
要点：市场为"剥离赔钱业务"立刻定价——困境反转的关键条目不是"亏了多少"，而是"止血步骤是否真实执行"。

### 案例2（原书案例，worked_example）：时代公司——主导类型定型＋补跑第二张专项表（15.1.6/15.1.7，L3312）

输入：时代公司已卖掉分公司、大幅削减成本（困境反转条目④⑥命中），林奇同时认定"事实上它也是一家隐蔽资产型公司"。
执行：主表按困境反转跑完后，补跑15.1.7专项层——条目①"公司的资产价值是多少？有隐蔽资产吗？"：仅有线电视部分业务的潜在价值就高达每股60美元；条目②"多少债务需要从资产中扣除"：原书此例未展开，如实标注缺口。
输出：股价每股100美元时，等于用每股40美元购买公司所有的其他业务（分部演算：100−60=40）。
要点：原书亲自示范了混用类型的处理——以主导类型定型，确认第二类型特征时只补跑对应的第二张专项表，而不是六张全跑（见 B 段）。

### 合成演练（标注：非书中按第15章清单的操作记录；素材为第11章书中事实，L2419-2451，框架为15.1）：La Quinta 按两层清单走一遍

输入（1978年前后的书中事实）：竞争对手联合旅馆副总裁主动称赞"在休斯敦和达拉斯地区它彻底把我们打垮了"；从得州起家、已在阿肯色与路易斯安那复制成功；去年新开旅馆数比前年增长20%，收益逐季增长；公司以每年50%的速度增长，市盈率只有10倍；债务不多（保险公司融资、不会抽贷）；仅3家券商追踪、大型机构持股不足20%；创始人之一以约半价卖出（为个人组合多元化）；前几年股价已翻番。

执行：
1. 归型：酒店业本身是缓慢增长行业，但公司自身高速增长且异地复制已验证——行业标签≠公司类型，归快速增长型。
2. 通用层六项：①P/E＝10倍，相对增速明显偏低→达标（同行业可比P/E书中未给→缺口）；②机构持股<20%、3家券商→利好；③内部人士：创始人半价卖出，按第8章口径"内部人士卖出通常没什么意义"（多元化目的），不作负分（买入信号未观察到→缺口）；④收益历史：持续稳定、逐季增长→达标；⑤负债："债务并不算太多"＋保险公司不抽贷→达标；⑥现金头寸：书中未披露→缺口。
3. 快速增长专项层：①产品占比：单一旅馆业态，无"大公司小产品"问题→达标；②增长率50%：高于25%→警示（落入"用怀疑眼光分析"区间，需其他条目补偿）；③复制验证：多个州已顺利复制→命中（这正是 Bildner's 反例所缺的条目）；④增长空间：中端市场无人竞争、"完全占领细分市场之前还有很大增长空间"→命中；⑤P/E vs 增长率：10倍对50%增速→命中（原书"便宜得令人难以置信"）；⑥扩张速度：新店增速20%、在加快→命中；⑦关注度：机构<20%、3家券商→命中。
输出：核查表6＋7项；缺口2项（同业P/E、现金头寸）；警示1项（50%增速的可持续性）；下一步路由：估值细算转 pe-valuation，现金复算转 financial-checklist-13。结果参照：林奇"尽可能多地大量买入"，10年上涨11倍（另一口径15倍）。

## A2 — 触发场景

**用户会在什么情境下遇到这类问题**

1. 决定认真研究一只具体股票（自选、荐股、身边发现、新闻触发），想系统、不遗漏地过一遍基本面。
2. 下单前想做一次"尽调"式核查，但不清楚该从哪几方面看、看哪些指标。
3. 已知或刚确定股票类型，要按类型专项核查——"周期股要看什么""困境反转股要查什么"。
4. 核对一篇研报或别人的分析有没有漏项，或给自己搭一张可复用的个股研究清单。

**语言信号（中英双写）**

- 中文："帮我全面分析这只股票""做个尽调""这只股票从哪几方面看""分析一下这家公司的基本面""买入前要核查哪些东西""帮我列个分析清单"
- 英文："full analysis of this stock" "due diligence checklist" "how should I analyze this company" "what should I look at before buying" "complete stock analysis"

**与相邻能力的区分**

- two-minute-story（两分钟独白）：本卡＝清单核查，逐项判"达标／警示／缺口"，交付核查表；独白＝理由陈述收口，把核查结论组织成"为什么买＋成功条件＋风险"的故事。"帮我组织买入理由"归独白，"帮我过一遍要点"归本卡；正常顺序是先本卡、后独白。
- stock-screening-checklists（双向筛选）：筛选＝准入把关，红旗命中直接排除、不深入；本卡＝对已过初筛或已决定认真研究的标的做深度逐项核查。"这票是不是雷"归筛选卡，"全面分析这只票"归本卡。
- classify-six-types：类型未定时先归型再进本卡；本卡消费其输出，不重复归型。
- pe-valuation／financial-checklist-13：本卡对 P/E、现金、负债只做占位核查；估值判定与财务数据链复算归那两张卡，本卡负责路由过去。
- research-info-gathering（U13 调研程序）：数据去哪里找、找谁问、怎么跑渠道归那张卡；本卡管查什么、怎么判。

**Step 1 — 确认类型（流程前置）**

- 输入已有类型标签→记录类型＋一句话判定依据，进 Step 2。
- 类型未定→**判停点：先调 classify-six-types 归型**（或按该卡规则现场归型）后再继续。为什么前置：P/E 与收益历史的解读方向随类型反转（通用层第1、4项注）。
- 多主业混合业务→以主导业务定型，只跑一张专项表；确认存在第二类型特征时，按原书时代公司做法补跑第二张（见 B 段第3条）。

**Step 2 — 通用层六项（15.1.1，L3244-3254，所有类型都过）**

| # | 核查项 | 判断方向（照录原书判据） |
|---|---|---|
| 1 | 市盈率 | 对这家公司来说市盈率是高还是低；与同行业中类似的公司相比是高还是低。解读随类型反转：周期型按"复苏时 P/E 降低"倒读（专项层②），未归型不得套"低＝便宜" |
| 2 | 机构投资者持股占总股本比例 | 越低越好 |
| 3 | 内部人士买入＋公司回购 | 二者都是有利的信号（内部人士卖出不作负分——第8章口径，La Quinta 创始人半价卖出后仍10年11倍） |
| 4 | 收益增长历史 | 时断时续还是持续稳定增长；只有隐蔽资产型可以说收益情况并不怎么重要。周期型的时断时续是常态，不得套"持续稳定"标准误判 |
| 5 | 资产负债情况＋财务实力评级 | 负债与股东权益比率是好是坏；财务实力评级如何 |
| 6 | 现金头寸 | 每股净现金是股价的底部下限（福特每股净现金16美元→股价不可能跌破16美元） |

注：15.1.1 通用层原文无股息条目——股息记录的深查在缓慢增长专项层（15.1.2）与 financial-checklist-13（指标5/6）；通用层第1项只判高低与同业比较，"P/E 等于或接近增长率"是快速增长专项层条目⑤，完整估值判定归 pe-valuation。福特净现金"16美元（15章约数）vs 16.30美元（13章精确复算）"为原书两处口径并存，复算链见 financial-checklist-13 卡。

**Step 3 — 专项层（15.1.2-15.1.7，只跑已定型那一类）**

缓慢增长型（15.1.2，L3258-3260）——命门是股息：

| # | 核查项 | 判断方向 |
|---|---|---|
| ① | 股息记录 | 买这类股票的目的是获得股息（不然为什么持有？）——核查是否长期持续派发股息、是否定期提高股息水平 |
| ② | 股息占收益的比率 | 低→经营困难时期仍有缓冲资金，收益降低仍能保证派发；高→股息能否顺利派发就相当危险 |

稳定增长型（15.1.3，L3264-3270）——命门是买入价格：

| # | 核查项 | 判断方向 |
|---|---|---|
| ① | 买入价格 | 几乎不可能破产倒闭的大公司，关键因素在于买入价格的高低——市盈率会告诉你股价是否过高 |
| ② | 多元化经营 | 检查可能进行的多元化经营情况，这有可能导致未来收益下降 |
| ③ | 收益长期增长率 | 检查收益的长期增长率，再看最近几年是否仍保持同样的增长势头 |
| ④ | 衰退期表现（打算永久持有时） | 看经济衰退与股市大跌时期的表现（锚：麦当劳1977年大跌表现好、1984年横盘、1987年遭重击但总体是不错的防御股；百时美1973-74年重创系严重高估，1982/1984/1987年表现好；Kellogg 除1973-74年外历次大跌都好） |

周期型（15.1.4，L3274-3282）——命门是存货与周期位置，P/E 反着读：

| # | 核查项 | 判断方向 |
|---|---|---|
| ① | 存货与供需 | 密切关注存货变化情况与供需平衡情况；市场上新竞争对手的进入通常是危险信号 |
| ② | P/E 反着读 | 业绩复苏时应预测到市盈率将会降低；收益达到最高峰时应预期增长周期可能即将结束——低 P/E 的周期股反而最危险，绝不可用成长股"低＝便宜"口径 |
| ③ | 行业周期规律 | 非常了解行业周期就是预测优势（汽车三四年扩张后三四年衰退、反复波动；人们可能推迟一两年换车，但迟早要买） |
| ④ | 下滑深度 | 下滑越厉害，复苏反弹越厉害；销售低迷比预期额外延长一年，反而会带来时间更长、幅度更大的反弹 |
| ⑤ | 当前位置 | 最近连续5年销售不错→可能正处上涨期中间阶段，也可能接近尾声；周期行业中预测上涨远比预测下降容易 |

快速增长型（15.1.5，L3286-3298）——命门是复制验证与增长空间：

| # | 核查项 | 判断方向 |
|---|---|---|
| ① | 产品销售占比 | 看好的产品销售收入在公司整个业务收入中的比重——L'eggs 之于小公司 Hanes 占比很大；Lexan 之于庞大的 GE 只占很小比重 |
| ② | 收益增长率 | 最喜欢20%-25%；对看起来能保持高于25%的公司十分担心；热门行业50%以上＝用怀疑的眼光分析 |
| ③ | 复制验证 | 已在一个以上的城市或乡镇顺利复制原来成功的经营模式——证明未来的扩张同样能取得成功 |
| ④ | 增长空间 | 业务是否还有很大增长空间——Pic 'N' Save 从南加州起家、还有49个州可扩张；西尔斯已遍布全美、再也找不到新市场 |
| ⑤ | P/E vs 增长率 | 股票交易价格的市盈率是否等于或接近公司收益增长率 |
| ⑥ | 扩张速度 | 在加快（去年3家今年5家）还是放慢（去年5家今年3家）；一次性销售型公司（Sensormatic：监视系统买一次足矣）销售放缓＝毁灭性打击，12个月内从42美元跌到6美元——须与剃须刀式重复购买型分开判读 |
| ⑦ | 关注度 | 只有很少机构持有＋少数分析师听说过＝低价买入的有利因素 |

困境反转型（15.1.6，L3302-3318）——命门是先活下来，再看好转：

| # | 核查项 | 判断方向 |
|---|---|---|
| ① | 生存能力（最重要） | 能否经受住债权人要求还款的打击而存活下来？多少现金？多少债务？（苹果：2亿美元现金、零债务→肯定不会破产） |
| ② | 债务结构与赔本续航 | 债务结构如何？赔本情况下还能经营多长时间？增发筹资能使公司复苏却稀释股份——复苏≠股价反弹（Navistar 教训） |
| ③ | 破产清算余值 | 已宣布破产的：清算偿还债务之后还给股东留下多少资产？ |
| ④ | 重整步骤 | 打算怎样摆脱困境重整旗鼓？剥离赔钱子公司了吗？剥离使收益大变（洛克希德停产 L-1011：每股收益两年从1.50涨到10.78美元，15美元买入4年最高60美元；德州仪器见 A1 案例1） |
| ⑤ | 业务好转 | 公司业务正在好转吗？（柯达：胶卷销售重新火爆、收益大增） |
| ⑥ | 成本削减 | 正在削减成本吗？效果如何？（克莱斯勒关厂＋零部件外包：从成本最高变成成本最低的汽车厂商之一） |

隐蔽资产型（15.1.7，L3322-3328）——命门是资产值多少、谁来兑现：

| # | 核查项 | 判断方向 |
|---|---|---|
| ① | 资产识别 | 公司的资产价值是多少？公司有隐蔽资产吗？ |
| ② | 债务扣减 | 有多少债务需要从这些资产中扣除掉？（首先要关注向债权人的借款） |
| ③ | 新债方向 | 公司是否正在借入新的债务，使资产价值进一步减少？ |
| ④ | 兑现人 | 是否有袭击并购者对公司感兴趣准备收购？——这会帮助股东从隐蔽资产的重估升值上大大获利 |

**Step 4 — 输出契约（交付物：一张完整核查表）**

```
① 类型：六类之一＋一句话判定依据（未定则先归型，不猜类型）
② 通用层核查表：6项 × 判定 ∈ {达标 / 利好 / 警示 / 缺口} ＋ 每项一句证据
③ 专项层核查表：该类型逐条 × 同上判定 ＋ 证据（多类型时列主导表＋补跑表）
④ 缺口清单：无法核查的数据项逐条列出（"待查XX数据"），不猜值、不默认通过
⑤ 下一步路由（按缺口与用户意图）：
   - 问"贵不贵／值不值" → pe-valuation（P/E 与增长率完整判定）
   - 现金／负债／账面价值需要复算 → financial-checklist-13（数据链复算）
   - 准备下单 → two-minute-story（把核查表收口为两分钟故事）
   - 类型存疑或疑似迁移 → classify-six-types
```

完成标准：通用层6行＋专项层全部条目各有一个判定或"缺口"标注，每项附一句证据；缺口项进入缺口清单待补。时间盒锚：全部核查在每只股票一两个小时以内完成（L3236 总纲）——超时说明范围跑偏或数据渠道有问题，先补渠道而不是无限研究。

## B — 边界

1. **清单不替代估值结论**：两层清单全部过完≠可以买——"贵不贵"归 pe-valuation，现金/负债数据链复算归 financial-checklist-13；本卡对 P/E、净现金只做占位核查并路由。
2. **缺口不猜值**：任何数据拿不到→标"缺口"，严禁编造或默认通过；缺口多的输出＝"研究未完成"，不是"核查通过"。
3. **混用类型以主导业务定型**：多主业公司按主导业务归型、只跑一张专项表；确认第二类型特征时按时代公司式做法补跑第二张，不得六张全跑——15.1.1 明说部分指标只适用特定类型，照单全跑本身就是误用。
4. **只过通用层＝假核查**（Bildner's 教训）：通用层全部通过仍不可买——快速增长型的生死条目"已在一个以上城市复制成功"在专项层；Bildner's 本地调研全过却漏问复制性，13美元跌到0.125美元。漏跑专项层正是该亏损的清单化根源。
5. **一次性销售与重复购买必须分开判读**（Sensormatic 教训）：同样是"销售放缓"，剃须刀式重复购买型是减速警告，一次性购买型是毁灭信号——12个月42美元跌到6美元，不得互相套用结论。
6. **跨类型 P/E 口径是头号误用**：不先归型就用 P/E 筛选，周期股的低 P/E 与成长股的高 P/E 会被同时错杀/错买——"先归类型再套专项"因此是流程前置而非建议。
7. **"机构持股越低越好"的时效边界**：该红利基于1980年代美股几千家无人覆盖的小公司；在机构与量化覆盖密度高的市场（如 A 股），此条权重须重估（见 A 股适配）。
8. **一两个小时是上限**：这张表的价值是"逐项过完、没有遗漏"的结构化覆盖，不是"研究越多越好"的授权；15.2 的32条要点是全书分散规则的复述清单（阶段1.5判定为重复条目），不得塞进本表扩容。
9. **隐蔽资产型的收益例外是双向的**：通用层第4项允许隐蔽资产型"收益情况不重要"，但前提是资产价值可估算且有兑现路径——只有破净、算不出真实变现价的，是账面陷阱不是隐蔽资产（归 financial-checklist-13 指标7）。

## A股适配（编译者补充，非原书内容）

### 数据获取渠道（替代原书《价值线》/标普/问经纪人）

- F10（同花顺/东方财富等）：总股本、十大流通股东、机构持股、股息记录、P/E（TTM）——替代价值线"一眼数据"。
- 巨潮资讯网（cninfo.com.cn）：年报/季报原文——资产负债表、分部数据、存货附注、产能利用率披露。
- 互动易／上证e互动：向公司提问的公开渠道，对应原书"给公司打电话"的低成本替代（问经营数据与扩张计划）。

### 核查表落地为 A 股字段（编译约定）

| 原书条目 | A 股落地口径 |
|---|---|
| 机构持股占比（通用层2） | 公募基金（季报重仓）＋北向（陆股通持股）＋QFII/RQFII 合并口径；"越低越好"降权为"中性偏正"——A 股覆盖密度高，机构零持股的小盘股常伴随流动性与治理风险 |
| 内部人士买入（通用层3） | 董监高增持公告＋实控人增持计划；回购须区分注销式（信号有效）与激励式（信号打折） |
| 负债与股东权益比率、财务实力评级（通用层5） | 有息负债率＝有息负债÷（有息负债＋股东权益）；"财务实力评级"无 A 股直接对应→现金短债比替代（编译约定） |
| 现金头寸（通用层6） | 每股净现金＝（货币资金＋交易性金融资产−长期借款−应付债券）÷总股本，科目映射详 financial-checklist-13 卡 |
| 股息记录（缓慢增长①②） | 上市以来分红明细＋股利支付率（分红总额÷归母净利润）；"长期持续派息"按上市年限缩放，"定期提高"看近5-10年逐年变化 |
| 收益增长历史（通用层4） | 归母扣非净利润同比序列（剔除一次性损益），防商誉减值/处置收益扭曲"时断时续"判读 |
| 周期型存货与价格（周期①） | 存货同比 vs 营收同比（同口径）；产能利用率/产销率（年报经营讨论）；产品价格（大宗价格或公司披露均价）——后两项为编译补充，原书15.1.4无此字段 |
| 衰退期表现（稳定增长④） | 2015、2018、2022-2024 等回撤期的相对收益记录，替代原书1973-74/1987年锚 |

### 披露频率（核查节奏）

- 存货/负债/现金：定期报告——年报与一季报不晚于4月30日、半年报不晚于8月31日、三季报不晚于10月31日；周期型存货信号按季跟踪。
- 机构持股：公募季报（滞后约2-3周披露重仓）、陆股通持股每日更新。
- 董监高增减持：实时公告。
- 分红：年度＋中期方案，缓慢增长型"逐年提高"按年报核查。
- 困境反转型的"生存能力"条目另有实时触发源：业绩预告（亏损/净资产为负预警）、债务违约/重整公告、退市风险警示（*ST）——A 股的 ST 制度给困境反转贴了明确标签，同时使"损失不可估算即排除"的条款更重要（博帕尔型边界）。
