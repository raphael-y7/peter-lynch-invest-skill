## I — 方法论骨架

这是林奇版的「公司体检程序」：不看年报的漂亮文字，直接翻到报表数字页，按固定顺序过十三个指标，每项都有明确算式和判断分支。底层逻辑是两条：股价长期由收益增长推动（指标12），但公司能不能活到收益兑现那天，由资产负债表决定（现金头寸、负债结构、账面真实性）。所以入口永远是资产负债表——先算「现金+有价证券−长期负债」的净现金头寸并折成每股，这一步顺带完成财务实力（权益/负债比）判断。然后逐项过：产品占比、P/E、股息记录、派息能力、账面价值、隐蔽资产、自由现金流、存货、养老金、增长率、利润率。每项要么加一个买入理由（净现金折价、隐蔽资产、高自由现金流、低利润率复苏弹性），要么插一面红旗（存货增速超销售、银行短债为主、养老金赤字、账面虚高、大存大贷式结构异常）。原书明言十三项排列与重要程度无关，价值在于「逐项过完、没有遗漏」。产出是一张核查表加总体财务健康判断，不是一个估值数字——估值是 pe-valuation-skill 卡的事。

## A1 — 应用示例

### 案例1（worked_example，原书案例）：福特1987年报三分钟数据链

来源：12.7节表12-1/表12-2 + 13.3节。输入→执行→结论全链：

1. 跳过全部文字，直翻合并资产负债表（表12-1）。
2. 现金头寸 = 现金及现金等价物 5,672.9百万 + 有价证券 4,424.1百万 = 10,097.0百万 ≈ 101亿美元；对照1986年（3,459.4 + 5,093.7 = 8,553.1百万 ≈ 85.5亿）→ 现金逐年增加，业务兴旺信号。
3. 长期负债 1,751.9百万 ≈ 17.5亿（1986年为2,137.1百万 → 债务减少，第二个兴旺信号）。短期负债1,803.3百万 ≈ 18亿：现金足以覆盖，按书口径在估算中忽略（假定存货等其他资产抵消）。
4. 净现金 = 101 − 17.5 = 83.5亿美元（精确复算 10,097.0 − 1,751.9 = 8,345.1百万）。现金高于债务 → 无论发生什么，福特不会破产。
5. 每股净现金 = 83.5亿 ÷ 5.11亿股（表12-2平均流通股本511.0百万）= 16.34美元，原文印16.30（作者取整口径）。顺带发现流通股 511.0 对上年 533.1 → 连续回购，第三个利好。
6. 实际买价 = 股价38 − 16.30 = 21.70美元；汽车业务预期EPS 7美元 → 名义P/E = 38÷7 ≈ 5.4倍，调整后P/E = 21.70÷7 = 3.1倍 → 决不卖出，结果后来又上涨40%以上。
7. 分部延伸（13.3节）：金融服务集团收益1.66美元/股 × 金融业平均P/E 10 = 16.60美元 → 汽车业务实际成本 = 38 − 16.30 − 16.60 = 5.10美元，对应汽车业务EPS 7美元。
8. 回退路径（不愿细算时问经纪人三问）：是否回购股票？现金是否高于长期债务？每股净现金是多少？

### 案例2（原书案例）：GCA vs 应用材料——负债结构定生死（13.4节）

同为芯片设备商、1985年下半年同样暴跌（GCA 20→12美元，应用材料16→8美元）。GCA负债1.14亿美元且几乎全是银行贷款，现金仅300万，主要资产是7,300万存货（电子行业明年可能只值2,000万）→ 行业复苏时破产，被以每股10美分收购。应用材料负债仅1,700万、现金3,600万 → 从8美元涨到36美元以上。同行业同周期，债务负担不同决定命运不同。衍生自救招：Micron濒临破产时发可转换债券（长期funded debt）置换银行短贷，股价4→24美元。

### 案例3（原书案例）：克莱斯勒——困境反转先查负债数量+结构（13.4节）

政府提供14亿美元贷款担保（关键：给了充分回旋余地）+ 账上10亿美元现金 + 卖坦克分部再得3.36亿 → 至少一两年内银行不会把公司逼入绝境 → 「汽车行业复苏+已成低成本厂商」的判断才站得住。（另案：1982年约6美元买入、5年约15倍，见 support-mapping c29。）

### 案例4（原书案例）：百时美——每股现金影响力取决于股价高低（13.3节）

现金16亿 − 长期负债2亿 = 净现金14亿，看似巨大；÷2.8亿流通股 = 每股净现金仅5美元。股价40美元时（5/40=12.5%）影响甚微；若股价跌到15美元（5/15≈33%）影响力相当大、股票变得非常便宜。同一笔净现金，结论随股价变。对照：波音1987年初股价40美元出头、每股现金27美元 → 实际买价约15美元，林奇随后重仓。

## A2 — 触发场景

1. 拿到一份年报/季报，要判断这家公司「财务底子」好不好、有没有隐藏价值或隐藏炸弹。
2. 听到某股票「账上现金特别多」「破净」「股息率高」「有隐蔽资产」，想验证数字是否成立、口径是否骗人。

## E — 执行步骤

### Step 0 — 输入契约（取数，缺项先补，不静默猜值）

数据来源：公司年报/季报（资产负债表、利润表、现金流量表及附注）；原书替代渠道为《价值线》、标普报告、问经纪人；A股替代渠道见「A股适配」。

必需字段（本期+上期，金额单位统一后带符号登记）：

| 块 | 必需字段 |
|---|---|
| 资产负债表 | 现金及等价物、有价证券/交易性金融资产、存货、股东权益合计、长期负债、短期借款/一年内到期负债（备查：应付账款合计） |
| 利润表 | 营业收入、税前利润、净利润、EPS |
| 现金流量表 | 经营活动现金流净额、购建固定资产等资本支出 |
| 股本与股价 | 总股本/流通股本（注明口径）、当前股价 |
| 记录类 | 股息历史（分红金额与连续性，尽量20–30年）、分产品/分部收入、存货计价方法（附注）、养老金/设定受益计划附注 |

缺项处理：缺现金流量表→指标9必须补，禁止用净利润替代现金流；缺历史股息→指标5/6记「记录不足」，不据此判死刑；缺分部数据→指标1只能估算并显著标注；缺存货或养老金明细→查附注，仍缺则该项记「无法核查」，不许跳过不留痕。

### Step 1 — 年报入口：六步现金头寸数据链（几分钟程序）

1. 跳过全部文字，直翻合并资产负债表（「纸张越便宜，信息越宝贵」）。
2. 现金头寸 = 现金及等价物 + 有价证券；与上年同口径对比——现金增加 = 兴旺信号。
3. 长期负债与上年对比——债务减少 = 兴旺信号；现金增长超过负债增长 = 资产负债表在改善。
4. 净现金 = 现金头寸 − 长期负债（短期负债若现金足以偿还则忽略，登记忽略理由）。
5. 每股净现金 = 净现金 ÷ 流通股本；顺带看股本逐年变化（减少 = 回购利好）。
6. 完成标准：得出「每股净现金」一个可复算数字，并回答「现金是否高于长期债务」。

### Step 2 — 十三项逐项核查（核心表）

| # | 指标 | 口径/公式 | 阈值/参照 | 解读分支 |
|---|---|---|---|---|
| 1 | 产品销售占比 | 该产品销售额 ÷ 总销售额（年报分部数据） | 无固定线；GE材料事业部占6.8% = 对股东意义不大 | ① 小公司大产品（L'eggs之于Hanes）→ 催化剂成立；② 大公司小产品（帮宝适之于宝洁、Lexan之于GE）→ 放弃该股或改找生产同产品的纯标的 |
| 2 | 市盈率 P/E | P/E = 股价÷EPS；含股息版 =（收益增长率% + 股息收益率%）÷ P/E | P/E≈增长率 = 定价合理；P/E为增长率一半 → 赚钱可能大；两倍 → 亏钱可能大；含股息版 ≥1.5 不错、≥2 很棒 | 完整判定归 pe-valuation-skill 卡（U05）；本卡只做交叉核对并在表中计数 |
| 3 | 现金头寸 | 每股净现金 =（现金 + 有价证券 − 长期负债）÷ 流通股本；实际买价 = 股价 − 每股净现金；调整后P/E = 实际买价 ÷ EPS | 净现金/股价 ≈12%（百时美5/40）影响甚微；≈33%（5/15）相当大；47%（7/15）巨大 | ① 净现金为正且占比大 → 市价暗含折扣，用调整后P/E重估（福特 5.4→3.1）；② 占比小 → 记录后跳过；③ 现金能否覆盖短期负债，决定短期负债可否在估算中忽略 |
| 4 | 负债（数量+结构） | 权益占比 = 股东权益 ÷（股东权益 + 有息负债）；结构 = 银行短债 / 长期债券占比 | 正常线：股东权益75% / 负债25%；福特91% / 不足10% = 非常强大；负债80% = 十分虚弱 | ① 现金 ≥ 短期负债 → 短期负债可忽略（登记理由）；② 银行短债为主 + 现金 < 短债 → 致命红旗，困境反转候选前置否决（GCA）；③ 长期债券为主 → 有多年喘息（应用材料；Micron发可转债置换短贷自救） |
| 5 | 股息 | 连续提高股息年数；股息率 = 每股股息 ÷ 股价 | 20–30年连续提高 = 最佳选择 | ① 有记录 → 抗跌支撑：1987年高息股跌幅不到大盘一半；20美元股价2美元息=10%，跌到10美元息率变20%托底；② 高债公司永远保证不了按时派息（Southmark 11→3美元后停息）；③ 膀胱理论：不派息公司现金积压，迟早乱并购泄压；④ 换股规则：派息但增长缓慢的老公司 → 不派息但增长快的新公司 |

| 10 | 存货 | 存货同比 vs 销售同比（同一计价方法、期末对期末） | 存货增速 > 销售增速 = 危险（销+10%、存+30%即触发） | ① 危险信号链：积压 → 明年更糟 → 新老产品竞争 → 被迫降价 → 利润下降；② 不景气公司存货连续下降 = 经营好转的第一个信号；③ 产品越接近成品越危险（迷你裙300→3美元仍卖不掉 vs 美洲虎35,000不会降到3,500）；④ LIFO/FIFO金例：卖450美元，后进成本400→利50，先进成本40→利410，跨口径不可直接比；⑤ 季报可每季跟踪 |
| 11 | 养老金计划 | 养老基金资产 vs 既定给付义务（vested benefit），年报披露 | 资产 > 义务 = 不必担心（USX 85亿 > 73亿） | ① 赤字 = 雪上加霜（伯利恒23亿 < 38亿 = 15亿赤字 → 问题解决前调低估值）；② 买困境反转股之前必查，防「无力承受的巨额义务」 |
| 12 | 增长率 | 收益增长率复利；利润率增幅换算 = 利润率增幅 ÷ 原利润率 | 表13-1：20%十年EPS 6.19（股价20×6.19=123.80）vs 10%十年2.59（≈26美元），差2.4倍；20%增长配20倍P/E优于10%增长配10倍P/E | ① 能年年提价不丢客户 = 好机会（烟草成本+4%、售价+6% → 利润率+2% → 利润率10%的公司收益+20%）；② 即便P/E从20降到15，A公司仍达92.85美元；③ 不外推30%+的十年增长（连3年都难持续） |
| 13 | 税后利润（工具：税前利润率） | 税前利润率 = 税前利润 ÷ 销售收入，同行业内比较 | 福特716亿收入、73.8亿税前 = 10.3%；Albertson's 3.6%；默克25%+；社会平均仅约5%（公众误猜20–40%） | ① 长期持有 → 选行业内高利润率（成本最低、萧条中最能活）；② 押注复苏 → 选低利润率（弹性：表13-2，B公司2→7.10即+255% vs A公司12→17.60即+47%）；③ 降价10%压力测试：12%→2%仍赚钱 vs 2%→−8%亏损成危公司 |

注（编译者口径核实）：指标4的75/25线，原书福特「权益91%/负债不足10%」= 股东权益18,492.7 vs 长期负债1,751.9（18492.7÷20244.6≈91%）——应付账款、应计负债等经营性负债不入此线，分母是有息负债口径。指标13原书节标题为「税后利润」，实际分析工具是税前利润率，照实登记。

### Step 3 — 判停与红旗规则

- 指标4查出「银行短债为主 + 现金 < 短债」→ 立即终止逐项流水，直接进 Step 4 标致命红旗（困境反转候选前置否决）。
- 指标7查出「高负债 + 资产变现性差」（Radice式）→ 同上，致命红旗。
- 其余红旗（存货超速、停息、负债80%、养老金赤字）记录后继续过完13项，不许中途弃表。

### Step 4 — 输出契约

1. 13项逐项核查表：每项 = 数值（含算式）/ 判定 ∈ {通过, 加分, 警示红旗, 致命红旗, 无法核查} / 红旗标记及一句原文依据。
2. 总体结论 = 财务健康等级 + 关键发现（≤3条：最大隐藏价值 + 最大风险）。
   - 等级（编译者约定，原书未规定分级）：A级 = 权益线达标 + 净现金为正 + 无红旗；B级 = 权益线达标，1–2面警示红旗；C级 = 负债线超标或净现金为负，无致命红旗；D级 = 任一致命红旗 → 财务否决。
3. 完成标准：13行全有数值或「无法核查」标注；每股净现金算式可独立复算；每面红旗附原文依据；结论一句话可被引用（例：「38美元实付21.70，调整后P/E 3.1——现金因素决定继续持有」）。

## B — 边界

1. **账面价值陷阱（不能只看PB低）**：佩恩中央、艾伦伍德、巴菲特织布机、Radice四案连环证明「破净捡便宜」是失败模式——负债是真实的，资产是估计的；高负债+虚资产可把正账面做成负价值。指标7只输出「真实变现价存疑」，不输出「便宜」。
2. **长期派息记录 ≠ 永不停息**：联合爱迪生这类「绝对安全」的公用事业蓝筹1974年也停发股息、股价近乎垂直崩跌（ce51）——股息记录是抗跌证据，不是保票；股息可持续性最终取决于资产负债表（Southmark，ce50）。
3. **LIFO口径是时代背景**：LIFO/FIFO两法对比出自1987年美国准则环境；中国会计准则自2006年起已取消后进先出法（IFRS亦禁）。两法对比仅作理解「存货计价扭曲收益」之用，A股实操退化为「存货同比 vs 销售同比 + 会计政策变更检查」。
4. **单季数据噪音**：存货、利润率单季波动大，一次读数不足为凭——须同比对照、连续多季跟踪，并用其他指标交叉验证（存货信号与现金流量、负债信号互证）。
5. **指标不代替估值**：13项是核查程序不是估值器——全过 ≠ 可以买，还须过公司分类（U01）、估值（U05/U08）、卖出纪律（U02）；原文明言「排列顺序与重要程度无关」。
6. **现金流量口径陷阱**：不扣资本支出的市价现金流比无意义（皮格钢铁：流入1亿−高炉8,000万）；只用经营现金流会选中重资产假现金牛。
7. **增长率外推上限**：原书拒绝用30%+做十年复利假设（「很难持续保持3年」）；表13-1是复利威力演示，不是预测授权。
8. **数据渠道是1987年美国的**：价值线/标普/问经纪人三渠道需按「A股适配」节替换后本卡才可用。

## A股适配（编译者补充，非原书内容）

### 科目映射（约定口径，算式照原书结构平移）

| 原书口径 | A股科目映射 | 备注 |
|---|---|---|
| 现金 + 有价证券 | 货币资金 + 交易性金融资产（可加其他流动金融资产，须注明） | 现金头寸分母口径统一为「总股本」 |
| 长期负债 | 长期借款 + 应付债券 + 租赁负债（剔除一年内到期部分） | 有息负债口径，不含应付账款等经营性负债 |
| 银行短期负债（bank debt） | 短期借款 + 一年内到期的非流动负债 + 其他流动负债中的有息部分 | 指标4「最危险一类」的对应物，优先查 |
| 流通股本分母 | 总股本（含限售） | A股有限售股：用「自由流通股本」会高估每股净现金，凡改口径必须注明 |
| 股息率 | 近12个月股息（TTM：最近年报分红 + 已实施中期分红）÷ 当前股价 | A股上市历史多不足30年，指标5的「20–30年记录」改为「上市以来记录」 |
| 75/25权益线 | 股东权益 ÷（股东权益 + 有息负债） | 直接用「负债合计/总资产」会错杀（经营性负债正常的公司），福特按此口径算是59%负债，而原书判91%权益——必须用有息口径 |
| 税前利润率 | 利润总额 ÷ 营业收入 | A股利润表直接披露利润总额 |
| 每股净现金 | （货币资金 + 交易性金融资产 − 长期借款 − 应付债券）÷ 总股本 | 合成演练：80+20−20−10=70亿 ÷ 10亿股 = 7元/股；股价15元 → 实际买价8元（与U06验证演练同构，可复算） |

### 查询渠道（替代价值线/标普/经纪人）

- 巨潮资讯网（cninfo.com.cn）：年报/季报原文——资产负债表、利润表、现金流量表、附注（存货计价、设定受益计划、受限货币资金）。
- 同花顺/东方财富 F10：股息率TTM、有息负债结构、存货同比、商誉余额——替代价值线的「一眼数据」功能。
- 交易所业绩预告/快报：补最新季度缺口；预告亏损或净资产为负时优先级最高。

### A股特有检查点

1. **合同负债/预收款项**：预收增长是下游需求先行指标（白酒、地产后周期等），与指标10存货信号配合——存货降+合同负债升 = 复苏确认度更高。
2. **商誉减值风险**：A股商誉不摊销、每年减值测试且计提不可转回——高商誉是账面价值陷阱的A股高发形态，指标7对商誉/净资产比高的公司红旗等级上调。
3. **大存大贷（存贷双高）**：货币资金高同时有息负债高、利息收入与货币规模不匹配 → 资金真实性红旗（归指标3/4联合标记），须查附注「受限货币资金」。
4. **退市规则下净资产红线**：期末净资产为负直接触发退市风险警示（*ST）——「账面价值为正」在A股是生存底线，指标7的净资产项从「参考」升为「红线检查」。
5. **养老金口径**：A股以应付职工薪酬附注 + 企业年金披露为主；仅少数公司有设定受益计划，可查「设定受益计划义务现值 vs 计划资产公允价值」，其余公司指标11降级为「职工薪酬附注无异常」即可。
6. **税收亏损抵扣不可平移**：美国当年50%税率+可结转，中国一般5年（特定行业延长）——佩恩式「抵扣即隐蔽资产」在A股数值与效力均打折，只能按附注实际可弥补亏损逐案算。
7. **LIFO已禁用**：见B段第3条，A股存货指标以「存货同比 vs 营收同比」为主，计价方法一致性检查退化为会计政策变更检查。
