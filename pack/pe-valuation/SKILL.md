# 市盈率与收益估值口径

> 一句话规则：股价跟着收益走——P/E与增长率比、与历史比、与市场比，(增长率+股息率)/P/E≥1.5才吸引人，绝不买超高P/E。

3. "即使关于市盈率你什么都记不住的话，你也一定要牢记一点：千万不要买入市盈率特别高的股票。只要坚决不购买市盈率特别高的股票，就会让你避免巨大的痛苦与巨大的投资亏损。"——第10章10.2（L2339）

## I — 方法论骨架

市盈率把抽象的"股价高低"翻译成一个可比较的数字：你为1元的年收益付了几元；在"收益永远不变"的假设下，它就等于收回本金所需的年数。收益当然会变，所以这个数字真正的用法是相对比较，而不是算出精确内在价值。

同一个P/E要用四把尺子分别量：和收益增长率比（增长快才配贵，加上股息后可打成一个分数）；和它自己的历史区间比（你现在付的价别人过去付过没有）；和整个市场的水位比（多数股票会同涨同跌，个股合理防不住整体收缩）；和价格-收益线的偏离比（同一逻辑的图形版，零计算）。

其中"P/E≈增长率"是主尺，"绝不买特别高的P/E"是独立于一切比较的否决红线——超高P/E隐含"从此直到永远"的高增长，历史上几乎从不兑现。未来收益本身不可预测，能做的只是核查公司正走在这五条增长途径的哪几条上；买入时机不猜顶底，只识别历史上反复出现的两个打折窗口。

## A1 — 应用示例

### 原书案例（作者亲历/转述，结果已交代）

- 麦当劳（1972）：运营依旧优秀，股价被哄抬到75美元、P/E 50倍；增长追不上预期，股价跌回25美元、P/E回归13倍。大跌约三分之二不是公司变坏，是买价太贵。
- 雅芳：股价140美元、P/E 64倍；有人测算其收入须超过美国钢铁+石油+加州收入总和才够买入者回本；收益不增反降，1974年跌到18.625美元。
- 宝丽来：1973年143美元、P/E 50倍（赌SX-70相机）；须向每个美国家庭至少卖4台才撑得住这个估值；书称18个月大跌89%，1974年只剩14.125美元。
- EDS：P/E高达500倍（研报还认为保守、应值1000倍）；此后多年业绩优秀，1974年股价仍从40美元跌到3美元——500倍等于收益不变要500年回本。
- 整体市场：1971年市场平均P/E升到20倍高点，随后1973–74年遭遇大萧条以来最剧烈暴跌；1982–87年整体P/E从约8倍升到16倍（同样收益付双倍价），是1987年崩盘前的警告信号。

### 合成演练（A/B公司对比演算；标注：原书未提供此对比案例，数字取自原书13.2示例与阶段1.5验证演练输入，可按原书规则复算）

输入——A公司：股价24.00元、前12个月EPS 1.20元、长期增长率g=15%、股息率2%。B公司：股价18.00元、EPS 3.00元、g=15%、股息率3%。

A公司：
- P/E = 24.00 ÷ 1.20 = 20.00倍（收益不变需20年回本）
- 得分 = (15+2) ÷ 20.00 = 0.85 < 1 → 判"差"
- 交叉验证：P/E(20)>g(15) → 前景令人担忧、股价面临下跌；但未达两倍（2×15=30）的"亏钱可能非常大"级
- 结论：偏贵，不买。

B公司：
- P/E = 18.00 ÷ 3.00 = 6.00倍
- 得分 = (15+3) ÷ 6.00 = 3.00 ≥ 2 → 原书评语"真是太棒了"（此例即原书13.2原例）
- 交叉验证：6.00 ≤ g的一半（15÷2=7.50）→ "赚钱的可能性就相当大"
- 结论：便宜，吸引。

两家公司两条口径同向，结论一致，方法收敛。

## A2 — 触发场景

1. 用户看中一只股票，问"现在这个价格贵不贵""估值算不算高""现在能不能上车"——本卡主场景。
2. "P/E 40倍还能买吗？""这只股票P/E只有8倍，是不是很便宜？"——对单一P/E数字的解读请求（含跨类型比较陷阱：低P/E不等于便宜）。
3. "业绩一直在涨，股价为什么不涨？""收益创新高股价反而跌，说明什么？"——价格线与收益线背离（原型：默克9年横盘中盈利年增14%，随后5年涨4倍）。
4. "现在大盘贵吗？要不要等大跌再买？"——整体市场P/E水位 + 两个买入窗口的识别。
5. 语言信号（中英）："贵不贵／估值／市盈率／高估／低估／P/E多少倍合适／买入时机"；"overvalued, undervalued, P/E ratio, valuation multiple, earnings up but price flat, is it too expensive to buy"。

与相邻能力的区分（初稿，阶段3回填定稿）：financial-checklist-13（十三项财务指标）回答"这家公司健不健康"（负债、现金、存货、机构持仓等核查），本卡回答"这个价格贵不贵"（估值判断）；常规顺序是先查健康再问贵贱。六类分类不归本卡，但本卡的前置门依赖分类结果（周期股须反转解读）。

## E — 执行步骤

**输入契约**：必需=当前股价（元）、前12个月（或上一财年）EPS（元/股）、公司六类分类结果；可选=长期收益增长率g（%）、股息率（%）、该公司近几个年度自身P/E区间、市场整体当前P/E。缺失处理：EPS≤0（亏损）→ 无P/E，口径1即停，结论记"不可估值（亏损）"，回退财务健康核查与红线否决；EPS异常小导致P/E离谱 → 先查一次性冲销/非经常损益（原书：请经纪人解释），排除后才继续；缺g → 口径2降级为纯P/E与历史/市场比较并标注"缺数据"，不得静默猜值。

**舍入约定**：所有比率（P/E、得分、比值）保留两位小数，除不尽四舍五入。

**步骤0 前置门**：确认公司六类分类。周期型 → 全部结论挂"反转解读"标记（见B1）；未分类 → 先完成分类再回来。完成标准：类型已确定并记录。

**步骤1 基础口径**：P/E = 股价 ÷ 前12个月EPS。例：凯玛特35÷3.50=10.00倍，即收益不变10年回本（3500美元买100股，年收益350美元）。完成标准：得出P/E（两位小数）并注明EPS所属期间。

**步骤2 P/E vs 增长率**：
- 粗比较：P/E=g 合理（可口可乐15倍↔预期年增15%）；P/E≤g÷2 偏便宜（12%成长股配6倍："盈利前景相当吸引人"）；P/E≥2g 危险（6%增长配12倍："十分令人担忧，股价将会面临下跌"）。
- 股息修正得分 = (g + 股息率) ÷ P/E。例（原书A公司）：(12+3)÷10=1.50；判定档：<1.00 差、约1.50 不错、≥2.00 最佳（原书例：(15+3)÷6=3.00）。
- 不派息公司：公式退化为P/E vs g纯比较，标注"无股息"。完成标准：得分（两位小数）+三档判定+粗比较方向。

**步骤3 vs 自身历史区间**：取该公司近几个年度P/E区间（原书数据源：价值线/标普报告/经纪人；A股见适配节），标记当前P/E位于区间上沿/中位/下沿。可口可乐原型：比较"你现在付的价"与"别人过去付的价"。上市太短无历史 → 跳过并标注。完成标准：区间值+当前位置。

**步骤4 vs 整体市场**：取市场整体P/E，与其自身历史常态比。原型：1982–87年从约8倍→16倍=为同等的收益付1982年的双倍价=大多数股票同时高估的警告；1971年整体20倍→1973–74年暴跌；机制=低利率（债券吸引力降，资金抬高股价）+牛市乐观情绪。当前显著高于常态 → 输出"系统性高估提示：暂缓新买入，个股合理防不住整体P/E收缩"。完成标准：整体水位与常态的相对位置+是否触发提示。

**步骤5 红线否决**：P/E特别高 → 直接判"贵，不买"，不再权衡其他口径。原书案例带：麦当劳50倍、雅芳64倍、宝丽来50倍、EDS 500倍，四案全部暴跌（约-66.7%至-92.5%）。实现约定（原书未给数值阈值，编译者以案例带下界定标）：P/E≥50.00 且 步骤2得分<1.00 → 触发红线。完成标准：触发/未触发。

**步骤6 价格-收益线背离**：同图叠加股价线与前12个月EPS线。价线远高于收益线 → 高估危险信号（原型：雅芳1972、The Limited 1983/1987；证据图：图10-1陶氏化学、图10-3 Shoney's/万豪/Limited、图18-1菲利普·莫里斯、图18-2默克）；价线低于收益线 → 机会；操作口径如实转述：低于线买、远高于线卖，作者注明"并非非得提倡，但想不出更好"。短期反常（收益涨股价跌=专业盘预期更高；收益跌股价涨=预期更差）不立即推翻规则。完成标准：偏离方向+幅度描述。

**步骤7 收益增长五途径核查**（不预测收益，只查计划与执行）：①削减成本 ②提高售价 ③开拓新市场 ④原有市场放量 ⑤重振/关闭/剥离亏损业务。列出该公司当前依赖哪几条、证据是什么、下次复查的对照点。完成标准：途径清单+证据来源+复查问题。

**步骤8 买入时机**：窗口一=年底避税抛售期（10–12月，投资者卖亏损股抵税、机构清理组合、低价股跌破6美元触发保证金与机构限制的强制卖出，好股票被打到惊人低价）；窗口二=股市崩盘/大跌/自由落体期（每隔几年出现；表17-1：Teledyne 1972–74年最低3美元→1987年最高390美元；表17-2：Dreyfus 1987年被抛到16美元，而每股扣除债务后的净现金有15美元）。结合步骤4：整体水位偏低+窗口期=最佳买入环境；水位偏高 → 宁可等窗口。完成标准：当前是否处于窗口（是/否/接近）。

**输出契约**：估值结论三态 + 依据链 + 周期股提示。
- 三态判定（编译者归并约定，各分档规则本身均出自原书）：**贵** = 步骤5红线触发，或得分<1.00，或P/E≥2g，或价线远高于收益线；**便宜** = 得分≥2.00，或P/E≤g÷2，且价线不高于收益线；**合理** = 其余情形（P/E≈g、得分1.00–2.00之间）。
- 依据链：口径1–6逐行结果（P/E值、得分、历史位置、整体水位、红线、背离方向），缺数据的口径标"缺"。
- 周期股/未分类股必须附加提示："P/E须按周期位置反转解读：利润谷底P/E虚高反而可能是买点，周期顶P/E最低反而可能是卖点。"

## B — 边界

1. 周期股不适用P/E≈g规则：利润谷底EPS塌陷使P/E虚高反而常是买点，周期顶盈利新高P/E最低常是卖点（通用动力案例：盈利创新高而股价先跌50%）。书中第17章与六类分类自行承认此反转，未分类的股票先分类再估值。
2. 亏损股与"小声耳语"类无收益股票没有P/E，本卡全部口径失效；不要用"市销率"等口径替代后假装仍是原书方法。
3. 未来收益不可能预测：作者明说业余者猜增长率与专业者"半斤八两"、专家预测"一错再错"。本卡只核查五途径的执行进度；任何输出"明年EPS=X元"的行为都越界，警惕把一致预期当事实。
4. 高增长不可持续是默认假设：超高P/E等于把"从此直到永远"的业绩提前支付（EDS 500倍=收益不变要500年回本）；"这次不一样"不予采纳。
5. P/E不可跨类型比较：公用事业7–9倍/稳增10–14倍/快增14–20倍是1980年代美股数据，绝对值不可平移，只保留"缓慢增长<周期<稳定增长<快速增长"的排序逻辑；"低P/E=便宜"是陷阱（陶氏化学的偏低P/E对沃尔玛并不偏低——苹果与桔子）。
6. 整体市场"8→16倍"判断产生于高利率时代，利率-估值联动的具体数值不可平移，只保留"整体P/E相对自身常态翻倍=警告"这一逻辑。
7. 只看个股不看整体水位是已记录的失败模式（1982–87失察案例）：个股估值再合理也防不住系统性P/E收缩。
8. 相邻易混：financial-checklist-13查健康不问贵贱，本卡问贵贱不查健康；两分钟独白是在估值结论之上讲"故事"，不是估值本身。

## A股适配（编译者补充，非原书内容）

1. 整体市场基准：不要复用道指/美股P/E绝对值。用中证全指或沪深300的PE-TTM及其历史分位（如近10年）做"风向标"；A股整体P/E的历史波动区间远宽于美股，只比较"当前分位 vs 历史常态分位"，不复用8倍/16倍数值。
2. 三种口径选TTM：行情软件同时提供静态PE（上一年报EPS，滞后）、动态PE（含盈利预测，与原书"不预测收益"立场冲突，慎用）、PE-TTM（滚动12个月，最贴近原书"前12个月收益"口径，推荐）。
3. 亏损/微利股失真：分母为负则PE无意义；微利股PE动辄数百上千倍无比较价值——这是原书"异常高P/E先查一次性冲销"的A股常态化版本：先看扣非净利润与非经常损益，再决定是否直接判"不可估值"。
4. 无年底避税节奏：美股10–12月避税抛售窗口在A股无对应税收机制，勿硬套。A股年末的机构排名调仓、春节前后效应等自有节奏仅作参考（非原书内容，使用前需自行验证）。崩盘/恐慌窗口的逻辑通用，保留。
5. 除权除息影响EPS：分红送转改变股本，历史PE band须用复权后数据；自行计算时确认EPS用最新摊薄股本口径，避免"价格已复权、分母没复权"的假P/E。
6. 数据源映射：原书"问经纪人/价值线/标普"→ A股用行情软件F10（历史PE分位、股息率TTM）、公司定期报告（五途径执行证据）；券商研报的增长率一致预期是预测值，按B3边界对待，不当作已知g使用。
