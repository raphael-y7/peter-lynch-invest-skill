# 六类公司分类判定

## R — 原文 (Reading)

> 一旦我确定了某一特定行业中的一家公司相对于同行其他公司而言规模是大是小之后，接下来我就要确定这家公司属于6种公司基本类型中的哪一种类型：缓慢增长型、稳定增长型、快速增长型、周期型、隐蔽资产型以及困境反转型。
> ——第7章 7.3（L1043）

> 一家具体公司的增长速度是快还是慢，要与整个国民经济的增长速度相比较而言。正如你可能会猜到的那样，缓慢增长型公司的增长速度非常缓慢，大致与一个国家国民生产总值（GNP）的增长速度相符，接近于最近美国国民生产总值年平均增长速度约3%。
> ——第7章 7.3（L1049）

## I — 方法论骨架 (Interpretation)

1. 分类是一切个股分析的第一道工序：不知道公司属于哪一类，期望收益、估值、核查清单、卖出规则全都套不上号。
2. 若因一个热门产品注意到公司，先算这笔账：产品收入÷公司总收入、产品利润÷公司总利润。占比小，产品再火也推不动业绩（帮宝适之于宝洁）；利润占比够大才是主驱动（L'eggs之于Hanes）。
3. 再判规模：与同行业其他公司比是大是小。规模越大涨幅上限越低，别指望巨无霸短期翻倍。
4. 然后归型，主标尺是公司自身的增长率（以净利/收益增速为主口径，编译约定），对照国民经济增速约3%分档：≈3%为缓慢增长；10%～12%为稳定增长；20%～25%为快速增长。数字之外用收益形态与公司状态兜住另外三类：收益按扩张-收缩规律大起大落是周期型；遭致命打击、濒临破产却可能起死回生是困境反转型；拥有市场没注意到的可估算资产是隐蔽资产型。
5. 归型永远看公司自己的增速，不看行业标签——年增2%的酒店业里照样有年均20%的万豪。
6. 周期与稳定的分水岭是收益形态而非名气：福特与百时美同为蓝筹，一个交替大盈大亏、一个20年只有一季下滑，衰退期跌幅80%对50%。
7. 归型后必须做迁移检查：类型会随生命周期改变（克莱斯勒从周期型到困境反转型又回到周期型），输出的是"当前类型"，不是历史标签。
8. 类型标签是后续一切的入口：每类有自己的期望收益区间、核查重点和卖出判据，不存在跨类型通用的法则。

## A1 — 应用示例 (Application Example)

1. **帮宝适 vs L'eggs 占比对照（worked_example，第7章 7.1 L1013-1015、L1021、L1023）**：帮宝适纸尿裤大受欢迎，但宝洁是规模庞大的公司，帮宝适收入仅占宝洁总收入一小部分，"产品热"传导不成"业绩大涨"；同样的产品成功放在小公司Hanes（L'eggs连裤袜）身上，对其净利润影响巨大。同节锚点：Bufferin阿司匹林收入占百时美总收入不到1.5%，利好新闻后股价仅涨50美分（L1021）；Sterling制药的阿司匹林收入占比6.5%、利润占比却接近15%——利润占比才是主驱动判据（L1023）。输入（产品收入占比、产品利润占比）→ 输出（产品热能否支撑买入推理）。

2. **克莱斯勒：周期→困境反转→周期的迁移（firsthand，第7章 L1364、L1424）**：克莱斯勒原是周期型公司，在周期低谷衰退到濒临破产、能否存活依赖政府贷款担保，此时按困境反转型判定；林奇1982年初以6美元买入，5年上涨15倍。成功重组后它又变回周期型公司——买入时的类型标签会过期，期望与卖出规则必须跟着"当前类型"切换。

3. **电力公用事业→缓慢增长型（worked_example，第7章 L1057、L1144、L1148）**：五六十年代电力公司以两位数扩张，是当时的快速增长型；70年代电力成本上升、用户学会节电后失去动力，成为"目前最常见的缓慢增长型公司"。识别特征：定期慷慨支付股息、走势图平坦如特拉华州地形。操作含义：增长率2%～4%的公司，股价难涨，不值得为它花时间。

4. **合成演练（非书中案例，按书规则复算）**：某白酒公司，行业头部大市值，近5年净利年增速约4%，股息率5%，无重大扩张计划。执行：①规模——同业头部大市值，涨幅上限受规模约束；②标尺——4%落在缓慢增长带（≈GNP基准3%附近，远低于稳定增长10%～12%）；③特征佐证——股息率5%慷慨派息、增长动力耗尽；④迁移检查——行业从历史高增长降档，符合"快速增长→缓慢增长"典型路径，确认输出"当前类型"而非历史标签；⑤输出：缓慢增长型，判定依据=增速4%+股息特征+行业降档史，期望以股息为主、股价涨幅有限。

## A2 — 触发场景 (Future Trigger)

**情境**：
1. 因一个火爆的产品、门店或新闻注意到一家上市公司，考虑买它的股票（帮宝适谬误高发区）。
2. 拿到一只股票（自选、荐股或持仓），想先搞清楚"这到底是哪类公司"再谈别的。
3. 问"涨了这么多了还能涨吗／这么大的公司还有空间吗"——规模与类型决定涨幅上限。
4. 持仓复查或读财报时发现增速、收益形态变了，怀疑"它是不是已经换了类型"。
5. 打算跟买别人推荐的股票前，检验自己能否独立回答"它属于六类中的哪一类"。

**语言信号（中英）**：
- "这是什么类型的股票/公司""它算周期股还是成长股" / "what kind of stock is this" "cyclical or growth"
- "XX产品卖爆了，能买它家股票吗" / "this product is everywhere, should I buy the stock"
- "都涨这么多了还能涨吗" / "how much upside is left"
- "这家公司是不是变了" / "has the story changed"
- "朋友/大V一直在买这只股票" / "my friend keeps buying this stock"

**与相邻能力的区分**：本卡只管归型——输出类型标签+判定依据+期望区间+下一步入口。估值（P/E 同型比较）、买入决策、分类型卖出判据、第15章核查清单是独立能力，在本卡输出之后调用；已明确类型的直接进入对应能力，不重复归型。概念问答（"什么是周期股"）只答定义，不启动归型流程。

## E — 执行步骤 (Execution)

**输入契约**：
- 公司名/代码（必需）
- 增长率：近3-5年净利（收益）年增速%（必需；口径约定：以净利/收益增长率为主，销售增速仅作参考——原书 L1047 列出多种口径未选定，此为编译约定）
- 收益趋势形态（必需）：平稳上行／规律性大起大落／持续下滑后企稳等
- 触发源为热门产品时：产品收入占比＋产品利润占比（必需；缺利润占比须补查后重判）
- 缺任一项：先向用户提问，不静默猜值。

**步骤**：
1. **收集输入**。完成标准：上述字段齐全，或已明确"产品占比不适用（非产品触发）"。
2. **产品占比测算**（仅产品触发时）。公式：产品收入占比＝产品销售收入÷公司总收入；产品利润占比＝产品利润÷公司总利润。裁决锚点：收入占比<1.5%（Bufferin锚，L1021）→可忽略，产品热不构成买股理由；利润占比≥15%（Sterling锚，L1023）→可认定主驱动。完成标准：给出两个占比数字＋锚点对照结论。
3. **判规模**。与同行业公司比大/中/小（总市值或营收对同业分位）。完成标准：给出相对规模定位，并说明涨幅预期上限（规模越大上限越低）。
4. **归型**（用公司自身增长率，不用行业标签）：
   - 增长≈3%或以下（2%-4%带）→ 缓慢增长型（佐证：定期慷慨股息、走势平坦）
   - 10%-12% → 稳定增长型（佐证：大市值、收益线平稳）
   - 20%-25% → 快速增长型（佐证：规模小、成长性强；警惕资金短缺与规模过大）
   - 收益按扩张-收缩规律循环 → 周期型
   - 致命打击＋濒临破产11章＋有起死回生路径 → 困境反转型（五子型细分：政府救助型／"谁会想到"型／"问题没预期严重"型／破产母公司中的好子公司／重整使股东价值最大化型，L1374-1384）
   - 可估算的未定价资产（每股资产价值＞股价）→ 隐蔽资产型
   完成标准：一个类型标签＋至少2条判定依据（数值与形态特征各1条）。
5. **迁移检查**。对照公司历史类型，确认当前类型；若发生迁移，注明方向。完成标准：明确"当前类型"及与历史标签的差异。
6. **输出类型化接口**（期望区间＋下一步入口）：
   - 缓慢增长：收益靠股息，涨30%-50%即达卖出线 → 入口：分类型卖出判据
   - 稳定增长：年均10%-12%，涨30%-50%考虑兑现，可作衰退防护仓 → 入口：卖出判据＋估值
   - 快速增长：10-40倍潜力，盯增长期结束信号（同店增长、扩张失速）→ 入口：快速增长型核查清单
   - 周期：时机决定盈亏，低P/E恰是警惕区 → 入口：周期时机判断＋卖出判据
   - 困境反转：与大盘关联最小，先查负债与现金、损失可测算性 → 入口：财务核查清单
   - 隐蔽资产：核心是资产可估算且市场未定价 → 入口：资产核查＋估值

**输出契约**：类型（六类之一；边界情形给最近似类型＋不确定标注，或两个候选类及各自成立条件）＋判定依据（≥2条）＋迁移状态（当前型 vs 历史型）＋期望收益区间＋下一步入口能力名。

**判停点**：
- 增长率落在4%-10%（缓慢/稳定之间）或12%-20%（稳定/快速之间）：按最近似归型，用特征佐证（股息、走势、规模）二次裁决，输出时标注"边界区间、不确定"；佐证相互冲突时输出两个候选类＋各自成立条件，不硬编单一标签。
- 产品占比落在2%-15%中间区（两锚点之间原书无连续阈值）：输出"占比证据不足以支撑产品驱动逻辑"，要求补利润占比数据后重判。
- 困境反转候选若损失/赔偿义务无法估算（博帕尔型，L1380）：直接输出"不可投——超出可判定范围"，归型终止于排除结论。

## B — 边界 (Boundary)

**反场景**：
- 类型已明确、问题在估值/买卖/持有复查——直接进入对应能力，本卡不重复归型。
- ETF、指数、行业板块整体——分类对象是单一公司，不适用。
- 概念解释类提问（"什么是周期股"）——答定义即可，不启动归型流程。

**书中警告**：
- 畅销产品≠好股票：Retin-A让强生两天市值增14亿美元，但该产品上年收入仅3000万美元（L1017-1019）；畅销玩具"椰菜娃娃"也救不了资产负债表糟糕的Coleco，股价65美元跌到1.75美元后破产（L167）；林奇亲身在心仪的Bildner's连锁店股票上惨亏（L165、11.2）。
- 大公司涨幅小：GE市值≈GNP的1%、年盈利超30亿，仍只能蜗牛式上涨——规模本身封住涨幅，别对大公司抱两年翻倍幻想（L1027、L1033-1037）。
- 蓝筹≠稳增：福特是周期股，衰退期跌幅80% vs 稳定增长股50%（L1352）——把周期蓝筹当稳定增长压箱底是类型误判的第一大亏损来源。
- 低P/E跨型比较是陷阱：周期顶部P/E最低恰是卖点，先分类再解释P/E。
- 破净≠隐蔽资产：必须满足资产"市场尚未定价"且能估算真实价值；账面价值是最常失真的指标。
- 困境反转排除条款：悲剧后果无法估量的公司（博帕尔的Union Carbide、Johns-Manville）要避开（L1380）。
- 类型会迁移：按历史标签操作已换型的公司（克莱斯勒重组成周期股后、三哩岛GPU反转完成后已是公用事业股）会套错全部规则。

**作者盲点（阶段0批判）**：
- 全部数值标尺（GNP≈3%、10%-12%、20%-25%）是1980年代美国口径，换市场、换年代须重设基准。
- 原书内部数字不一：快速增长 L1049 称"20%～30%甚至更高"，L1270 定义"年平均20%～25%"；增长率口径（销售/利润/盈利）原书未固定——本卡取净利/收益增速为主，属编译约定。
- "问经纪人"兜底（L1436）在A股散户场景不可行，替代方案见A股适配小节。
- 隐蔽资产"华尔街没注意到"无可操作阈值，现代信息环境下该判定须用机构覆盖度等代理指标重建。

**相邻混淆**：
- 周期型 vs 困境反转型：周期型是"规律性的扩张-收缩，会自己回来"；困境反转是"致命打击、濒临破产11章，不会自动回来"（原书："它们不是业务将会复苏的周期型公司"，L1358）。判据：收益形态是循环还是一次性崩溃，以及是否存在生存问题。
- 周期型 vs 稳定增长型：看收益形态而非名气——交替大盈大亏（福特）vs 20年仅一季下滑（百时美）。
- 缓慢 vs 稳定：≈3% vs 10%-12%；缓慢型的存在理由是慷慨股息。

## A股适配（编译者补充，非原书内容）

以下均为编译者补充，非原书内容；原书标尺为1988年美国背景。

- 行业与规模对照：用申万一级行业确定同业集合，规模用总市值在同业中的分位（如前20%记为大盘）替代"相对同行大小"的目测。
- 增长率数据与口径：数据源用同花顺/东方财富/Wind；以"归母扣非净利润同比"为主口径，剔除一次性损益；分红送转除权会使未复权每股收益失真，须用复权价或净利润总额口径计算增速，避免把除权误判为负增长。
- 增长率标尺平移：GNP≈3%的基准改为中国名义GDP增速（注意名义/实际口径）；缓慢/稳定/快速三档随基准整体平移，属适配层设定。
- 缓慢增长型的A股对应：成熟国有大行、电力/水务/高速公路等公用事业、渗透已饱和的消费品龙头——共同特征是低增速＋高分红，与原书"电力公用事业"同构。
- 周期型的A股识别：煤炭/有色/石油等资源品、航运（运价周期）、生猪养殖（猪周期）、券商（市场Beta）、化工、地产链。
- 隐蔽资产的A股常见形态：一二线城市土地储备与自营物业、矿权、按成本法记账的长期股权投资（含未上市与已上市股权）、账上大额货币资金与理财；仍须满足"市场尚未定价＋可估算"两条。
- "问经纪人"替代：A股散户无经纪人可问，用机构关注度代理——券商研报覆盖家数、基金持仓比例、陆股通持股；覆盖寥寥＋资产可估算，更接近原书"华尔街没注意到"。
- A股特有风险：涨跌停与题材炒作让"产品热"更快透支进股价（帮宝适谬误更常见）；ST/*ST制度给困境反转贴了明确标签，但退市风险也使"损失不可估算即排除"的条款更重要。
