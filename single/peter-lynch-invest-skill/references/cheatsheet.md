# 决策规则速查 — 彼得·林奇的成功投资（One Up on Wall Street）

| 能力 | 一句话规则 |
|---|---|
| 六类公司分类判定 | 先归类再谈买卖——用增长率与收益形态把公司放入六类之一，类型决定一切后续规则 |
| 分类型卖出判据 | 卖出看类型不看浮盈浮亏——缓慢增长涨30-50%兑现、周期在低P/E时警惕、快速增长盯同店与扩张失速 |
| 双向筛选清单（13条选股准则+避而不买清单） | 双向把关——枯燥乏味是优点（13条准则加分），热门花哨是红旗（6类避买直接排除） |
| 市盈率与收益估值口径 | 股价跟着收益走——P/E与增长率比、与历史比、与市场比，(增长率+股息率)/P/E≥1.5才吸引人，绝不买超高P/E |
| 13项财务指标核查 | 年报直翻资产负债表——现金头寸、负债结构、股息记录、账面价值陷阱、隐蔽资产、现金流、存货、养老金、增长率、利润率十三项逐项过 |
| 股票分析要点一览表（第15章通用+六类型专项核查） | 按类型逐项核查——先过通用要点（P/E、净现金、负债、股息、增长），再按六类型专项清单补齐 |
| 12种危险说法识别与反驳+衍生品否定 | "不会再跌了""3美元能亏多少"等12种说法是危险信号——逐条识别反驳；期权期货卖空一律不碰 |
| 两分钟沉思独白 | 下单前两分钟把"故事"讲清楚——为什么买、成功条件是什么、风险在哪，讲不清就不买 |
| 定期重新核查 | 每隔几个月重查基本面——新情况触发核查，价格波动本身不是；快速增长公司分三阶段，别在衰退期当扩张期拿 |
| 组合构建与持有纪律 | 3-10只、类型搭配、只换股不闲置——卖出鲜花抱住野草是最大错误；业余者不设止损指令 |
| 入市自我测试与业余优势定位 | 入市先过三问——有房吗、两三年要用的钱吗、有耐心与认错的素质吗；业余优势在身边，不在消息 |
| 信息获取与调研程序 | 调研只认事实和数据——年报数字、IR问答、实地观察三个层级，形容词一律不听 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
